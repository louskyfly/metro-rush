# Métro Rush

Runner 3D pour iPad (paysage) en three.js : cours sur les rails, esquive les trains et les barrières, ramasse les pièces et échappe au gardien et à son chien.

Jouer : https://louskyfly.github.io/metro-rush/

- Glisser ← → : changer de voie · ↑ : sauter · ↓ : rouler · double-tape : planche (une par partie)
- Clavier : flèches, Espace (planche), P (pause)
- Bonus : aimant, jetpack, super-saut, score x2
- Boutique de personnages et de planches avec les pièces (sauvegarde sur l'appareil)
